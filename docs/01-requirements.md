# 01. 요구사항

## 1. 목적

흩어진 아이 발달 자료(어린이집 알림장, 근거 DB, 보고서, 검진, 가족 관찰)를 **가족이 휴대폰에서 한곳에서 보고, 같은 방식으로 기록**하게 한다.
기존 Python 파이프라인(수집 → 검증 → 보고서)의 **검증 문화를 그대로 잇는다**: 판정하지 않고, 출처를 남기고, 숫자는 자료에서 다시 센다.

## 2. 사용자

| 사용자 | 기기 | 주 용도 | 빈도 |
|---|---|---|---|
| 엄마 | 휴대폰 | 알림장·보고서 보기, 기록 입력 | 매일 |
| 아빠(관리자) | PC·휴대폰 | 동기화·배포·기록 입력 | 매일·주 1회 |
| 조부모 2명 | 휴대폰 | 기록 입력(저녁 식사 등), 가이드 보기 | 주 수회 |

- 모두 **같은 가족 PIN** 하나로 들어온다(결정 D-02). 개인 계정은 없다.
- 입력할 때는 **기록자 이름을 고른다**(감사 추적용, 보안 수단 아님).
- 큰 글씨·한 손 조작이 기본이다(조부모 사용).

## 3. 범위

### 1차 (M1~M5)

| ID | 기능 | 요약 |
|---|---|---|
| F1 | 보고서 보기 | 발달 보고서·행동 가이드·위키·가이드 문서를 앱 안에서 본다 |
| F2 | 가족 기록 입력 | 저녁 식사·울음·손 뜯기·밴드 연습 기록을 입력하고 요약을 본다 |
| F3 | 검진·성장 | 영유아검진 결과와 키·몸무게·머리둘레·BMI 성장 곡선 |
| F4 | 알림장 검색 | 날짜·낱말·반으로 알림장을 찾고 원문을 본다 |
| F5 | 키즈노트 갱신 | 새 알림장을 수집해 반영한다(반자동, `07-kidsnote-sync.md`) |
| F0 | 접속 보호 | 서버 확인 PIN, 세션, 시도 제한 |

### 범위 밖 (1차)

- 사진·동영상 보기(용량 10GB 이상, R2 무료 한도 초과 → 2차 검토)
- 개인별 계정·권한 분리
- 알림 푸시, 다국어
- 발달 **판정** 기능(설계상 영구 제외 — 원칙 P1)

## 4. 기능 요구

### F0 접속 보호
- F0-1 모든 페이지·API·자료는 **서버가 PIN 세션을 확인한 뒤에만** 응답한다.
- F0-2 PIN 은 서버 비밀값(해시)으로만 저장한다. 브라우저 코드에 PIN 이 없다.
- F0-3 실패 5회 → 15분 잠금(IP 기준). 틀린 PIN·맞는 PIN 의 응답은 최소 400ms 로 균일하지만, **잠금 중의 `429` 는 PIN 을 대조하지 않고 즉시 응답한다**(지연 없음. 잠금 상태는 숨길 수 없고, 잠금 중 시도는 기록되지 않아 잠금이 연장되지 않는다). 전역 30회/시간 초과 시 1시간 전체 잠금.
- F0-4 세션 30일, 기기별. 관리자는 **전체 세션 무효화**를 할 수 있다(PIN 변경 시 자동).
- F0-5 검색엔진 색인 금지(`X-Robots-Tag: noindex`, `robots.txt`).

### F1 보고서 보기
- F1-1 기존 파이프라인이 만든 HTML 보고서를 그대로 보여준다(재구현하지 않는다).
- F1-2 각 보고서에 **생성일·원본 커밋·검증 결과(VERIFY OK 여부)** 를 표시한다.
- F1-3 마크다운 문서(guide/wiki)는 앱 안에서 읽기 좋게 렌더링한다.

### F2 가족 기록
- F2-1 기록 종류: 저녁 식사(`meal`), 울음·떼(`cry`), 손 뜯기(`skin_pick`), 밴드 연습(`bandage_step`). 종류 추가는 스키마 수정 없이 설정으로(`03-data-model.md` §3).
- F2-2 한 화면에서 **30초 안에** 입력 완료(목록 고르기 중심, 자유 입력은 메모 하나).
- F2-3 기록은 수정·삭제 가능, 변경 이력 보존(소프트 삭제).
- F2-4 요약: 1주차/2주차 비교, 간식×먹은 양 교차표 등 기존 엑셀 기록표와 같은 지표.
- F2-5 경고 표시: 떼쓰기 25분 이상, 사람 때림 → 해당 가이드의 "도움 받을 때" 링크.
- F2-6 오프라인 입력: 연결이 끊겨도 입력을 받아 두었다가 다시 연결되면 보낸다.

### F3 검진·성장
- F3-1 검진 기록(차수·날짜·계측·판정·판독 상태 CONFIRMED/UNCERTAIN)을 본다.
- F3-2 성장 곡선: WHO/KR 백분위 곡선 위에 측정점. 백분위는 LMS 로 다시 계산해 결과지 값과 나란히 보인다.
- F3-3 착의 측정 등 **측정 조건 메모**를 함께 표시한다.

### F4 알림장 검색
- F4-1 날짜 범위·반·낱말 검색, 결과에 일치 부분 강조.
- F4-2 원문(본문+댓글, KST)을 출처 링크와 함께 보여준다.
- F4-3 483일 기준 검색 응답 1초 이내.

### F5 키즈노트 갱신
- F5-1 관리자가 PC에서 한 번 실행하면: 수집 → 기존과 대조 → 일자별 생성 → 검증 → D1 적재.
- F5-2 기존 기록이 바뀌었거나 사라졌으면 **적재를 멈추고** 차이를 보고한다.
- F5-3 앱에 마지막 동기화 시각과 건수를 표시한다.

## 5. 원칙 (변경 금지)

| ID | 원칙 |
|---|---|
| P1 | **판정하지 않는다.** 발달 상태 값은 `관측됨/미관측/자동탐지불가`, 검진은 결과지 문구 그대로. "달성/미달/정상/지연" 등 판정 어휘를 앱이 만들어 내지 않는다 |
| P2 | **출처를 남긴다.** 모든 인용·수치에 원본(날짜·파일·논문 ID)을 붙인다 |
| P3 | **숫자는 자료에서 센다.** 화면의 건수·기간은 손으로 쓰지 않고 쿼리로 만든다 |
| P4 | **아이 자료는 공개 저장소·정적 파일에 두지 않는다** (`04-security-privacy.md`) |
| P5 | **무료 범위에서 운영한다.** 유료 API·유료 요금제를 전제로 하지 않는다 |

## 6. 품질 기준 (수용 기준 요약)

| 영역 | 기준 |
|---|---|
| 보안 | 세션 없이 접근 가능한 아이 자료 0건(자동 점검 Q-SEC) |
| 정확성 | 적재 후 D1 건수 = 원본 건수(알림장 일수·건수·댓글), 인용 대조 불일치 0 |
| 성능 | 모바일 4G 기준 첫 화면 2.5초 이내(LCP), 검색 1초 이내 |
| 접근성 | WCAG 2.2 AA 대비, 터치 영역 44px 이상, 기본 글자 17px 이상 |
| 가용성 | 무료 한도 초과 시 **닫힘(fail closed)** — 자료 노출보다 접속 불가를 택한다 |
| 비용 | 월 0원(Cloudflare·GitHub 무료 범위) |
