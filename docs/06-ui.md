# 06. 화면

## 1. 설계 기준

| 기준 | 값 | 이유 |
|---|---|---|
| 기준 화면 | 360×740 (안드로이드 소형) → 1280 까지 반응형 | 조부모 휴대폰 |
| 기본 글자 | 17px, 줄간격 1.6, 설정에서 "큰 글씨" 20px | 조부모 |
| 터치 영역 | 최소 48×48px, 버튼 간 8px 이상 | WCAG 2.2 2.5.8 보다 여유 |
| 대비 | 본문 4.5:1 이상, 큰 글씨 3:1 이상 | WCAG AA |
| 입력 | 목록 고르기(큰 칩 버튼) 우선, 키보드 입력은 메모 하나 | 30초 입력(F2-2) |
| 탐색 | 하단 탭 4개, 깊이 2단계 이내 | 한 손 조작 |
| 다크 모드 | 시스템 설정 따름 | — |
| 문구 | 판정 어휘 금지(P1), 숫자는 API 값만(P3) | 원칙 |

### 2-1. 자료 탭 화면 (T-C2)

| 경로 | 화면 | 내용 |
|---|---|---|
| `/library` | S40 | 「건강 기록」 입구 카드 2장(검진 N건·성장 곡선) + 보고서/가이드/위키 묶음 카드(제목·생성일·검증 배지). 검증 배지는 적재 때 원본 커밋이 기록된 문서에만 「검증 통과/미통과」 |
| `/library/doc/:slug` | S41 | 마크다운: 안전 렌더(원시 HTML·위험 링크는 글자 그대로, 링크 `rel=noopener`), 목차(제목 `#`/`##`) 접이식 + 점프, 본문 폭 38em·큰 글씨. HTML: `<iframe sandbox="allow-scripts">` 로 `/raw`(CSP `frame-src 'self'` 로 열림) |
| `/library/checkups` | S42 | `data-tone="serious"`. 검진 카드(회차·검진일·나이·종합 소견·참고 사항·발달 평가는 결과지 문구 그대로) + 계측 표(항목·값·결과지 백분위·판독). `UNCERTAIN` 은 「판독 불확실」 배지 + 설명. 원본 사진 보기는 사진 지원 때(이번에는 없음) |
| `/library/growth` | S43 | 측정 종류 칩(키·몸무게·머리둘레·BMI), 직접 그린 SVG 차트(기준 3·50·97% 옅은 선, 아이 점 진하게, 판독 불확실은 빈 점), 점을 누르면 값·날짜·측정 조건, 「표로 보기」 대체(차트와 같은 정보 + 그 나이의 기준값). 차트 라이브러리 없음 |

- 화면 코드는 `src/features/library/`, 모두 `React.lazy` 로 분할(초기 번들 예산, Q-PERF). 표시 문구에 판정 어휘가 없는지는 e2e 가 검사한다.

## 3. 핵심 흐름

### 저녁 식사 기록 (목표 30초)
```
홈 [오늘 기록하기] → 종류 [🍚 저녁 식사] → 
 Q1 미리 알렸나 [O][X] → Q2 불렀을 때 [바로 옴][달래서 옴][안 옴] →
 Q3 떼쓴 시간 [0][5][10][15][20][25+][직접] → Q4 던지기·때리기 → Q5 먹은 양 →
 Q6 저녁 전 간식 → Q7 아팠나 → Q8 휴대폰 → (메모) → 기록자 [엄마…] → [저장]
```
- 질문은 한 화면에 하나씩, 고르면 자동으로 다음. 뒤로 가기로 수정.
- 저장 후 "이번 주 3번째 기록" 같은 사실만 보여 준다(칭찬·평가 문구 없음).
- 경고 조건 충족 시: "떼쓰기 25분 이상이 기록됐어요. 도움 받을 때 기준 보기 →" (가이드 링크).

### 알림장 찾기
검색어 입력(디바운스 300ms) → 결과 목록(날짜·첫 줄·일치 강조) → 상세 → 좌우 넘기기로 이전/다음 날.

## 4. 상태 표시 규칙

| 상황 | 표시 |
|---|---|
| 오프라인 | 상단 띠 "오프라인 — 기록은 저장해 두었다가 연결되면 보내요 (대기 2건)" |
| 동기화 오래됨(14일 초과) | 홈 카드 "마지막 동기화 9월 28일" 회색 → 주황 |
| 판독 UNCERTAIN | 노란 배지 "판독 불확실" + 설명 |
| 한도 초과(503) | "오늘 사용량이 많아 잠시 쉬어요. 내일 오전 9시 이후 다시" |
| 빈 결과 | 이유와 다음 행동("기간을 전체로 바꿔 보세요") |

## 5. 디자인 토큰 (`src/styles/tokens.css`)
- 색: `--c-bg`, `--c-fg`, `--c-accent`(파랑), `--c-warn`(주황), `--c-alert`(빨강), `--c-ok`(초록) — 라이트/다크 각각.
- 크기: `--fs-base: 17px`, `--fs-lg`, `--fs-xl`, `--tap: 48px`, `--radius: 12px`, `--space-1…6`.
- 아이콘: 이모지 대신 SVG 아이콘(일관 렌더링). 기록 종류는 아이콘 + 글자 함께.
- 테마: 기본·크레용·숲 3종(ADR-0007). 전체 토큰 계약·게이트는 `docs/design/theme-system.md`. 화면 코드는 토큰·공용 클래스만 쓰고 hex 를 직접 쓰지 않는다.
- S90 설정에 「화면 테마」(기본/크레용/숲)과 「더 보기 → 디자인 미리보기」(S91, 합성 자료로 전 컴포넌트·화면 시안; 모든 사용자에게 보임)를 둔다.
