# ADR-0005: 기존 Python 파이프라인을 정본으로 재사용

- 상태: 승인 (2026-09-28)
- 관련: docs/02-architecture.md, docs/04-security-privacy.md

## 배경
기존 수집·생성·검증 스크립트(T1~T7, G1~G13, W1~W5, R1~R11, C1~C22)가 이미 정확성을 보증한다.

## 결정
웹앱은 보고서를 재구현하지 않는다. `tools/ingest` 는 기존 산출물을 읽어 검증·적재만 한다. 보고서 HTML 은 그대로 sandbox iframe 으로 보여준다.

## 결과
검증된 결과를 재사용해 오류 표면을 줄인다. 대신 보고서 화면은 앱 디자인과 완전히 같지 않다(2차에서 점진 이관 검토).

## 검토한 대안
보고서를 React 로 재구현(기각: 1차 범위·검증 비용 과다).
