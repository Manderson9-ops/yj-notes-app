# ADR-0006: 키즈노트 수집은 가정 PC 에서 반자동

- 상태: 승인 (2026-09-28)
- 관련: docs/02-architecture.md, docs/04-security-privacy.md

## 배경
키즈노트 API 는 로그인 세션 쿠키가 필요하다. 클라우드 자동 수집은 비밀번호·쿠키를 서버에 둬야 하고 약관·차단 위험이 있다.

## 결정
관리자 PC 의 로그인된 브라우저 안에서 API 를 호출해 내려받는다(v1 수동 실행, v2 Aside 주간 루틴). 쿠키는 저장하지 않는다. 대조에서 기존 기록 변경이 발견되면 적재를 멈춘다.

## 결과
계정 위험을 최소화한다. 대신 "완전 자동"은 아니며, 관리자 PC·브라우저 로그인 상태에 의존한다.

## 검토한 대안
Cloudflare Cron 에서 로그인(기각: 자격증명 클라우드 보관), 키즈노트 공식 API(없음).
