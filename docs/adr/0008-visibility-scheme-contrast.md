# ADR-0008: 화면 밝기 선택과 선명하게 보기(가시성 개선)

- 상태: 승인 (T-D1)
- 관련: ADR-0007, docs/design/theme-system.md, docs/06-ui.md S90·S91

## 배경
독립 감사에서 화면 가시성이 6.1/10 이었다(기본 라이트 7.0 … 크레용 다크 4.4). 카드 테두리 대비가 1.2~1.5:1 이라 카드가 구분되지 않고, 선택 상태가 색만으로 표시되며, 보조 글자가 7:1 에 못 미치고, 다크에서 테두리·강조색이 번쩍였다. 헤더 설정 아이콘(톱니)은 해(밝기 전환)처럼 보여 어르신에게 모호했다. 조부모가 쓰는 앱이라 가독성을 우선한다.

## 결정
1. **토큰 재조정**: 6조합(3 테마 × 라이트/다크) 모두 본문 12:1, 보조·흙색·링크 7:1, 경계 3:1, 상태색(-bg 위) 7:1. 다크는 순수 검정 대신 연한 면(elevation = 더 밝은 면, Material dark / M3 tone 면)과 채도를 낮춘 강조색을 쓴다.
2. **화면 밝기 설정**(`yj.scheme`: system|light|dark, 기본 system): `src/lib/scheme.ts` 가 첫 렌더 전에 `<html data-scheme="light|dark">` 를 정한다. 다크 토큰은 `prefers-color-scheme` 미디어쿼리가 아니라 `:root[data-scheme="dark"]`(테마는 `[data-theme][data-scheme="dark"]`)에 둔다. `system` 일 때만 matchMedia 변화를 따른다. 주소창 색(theme-color)도 실제 적용 밝기를 따른다.
3. **선명하게 보기**(`yj.contrast`: normal|high, 기본 normal; KRDS 선명한 화면 모드 참고): `<html data-contrast="high">` 가 어느 테마·밝기 위에도 얹힌다(`contrast-high.css`). 본문 15:1, 보조 10:1, 테두리 7:1, 장식·질감·오프셋 그림자 끔, 테두리 2px, 포커스 링 3px.
4. **가시성 컴포넌트 규칙**: 대화상자 = 가장 높은 면(surface-2) + 진한 테두리, 눌리는 카드는 진한 테두리 + 화살표, 선택 상태는 색 + 외곽 링 + 굵기, 활성 탭은 위쪽 막대 + 굵은 글씨, 라디오·체크 상자는 모든 테마 공통 모양, 위험 단추는 경고 아이콘, 헤더 설정 단추는 아이콘 + 「설정」 글자.
5. 두 설정 모두 이 기기 `localStorage` 에만 저장한다(서버·D1 저장 없음). 설정(S90)과 디자인 미리보기(S91)에 같은 스위치를 둔다.

## 결과
- 대비 게이트는 `contrast.test.ts` 가 6조합 × (일반, 선명) 으로 자동 확인한다(숲 질감 최악 지점 포함).
- 명세 값 중 링크·상태색·숲 질감은 게이트를 넘기려고 같은 색상에서 명도만 조금 조정했다(값은 theme-system.md §6).
- 숲의 수채 번짐·종이 결·워시를 옅게 줄였다(본문 12:1 을 지키기 위해).
- 크레용 정적 카드는 손그림 외곽선을 쓰지 않는다(눌리는 카드·버튼·칩만 먹선 + 오프셋 그림자 = 눌러 볼 수 있다는 표시).

## 2차 결정 (독립 검토 8.2/10 반영)
- 카드 규칙을 모든 테마에 하나로: 안 눌리는 카드 = `--c-line`(3:1) 테두리만·그림자 없음, 눌리는 카드 = `--c-border` + 화살표(크레용만 오프셋 그림자).
- 장식 구분선은 `--c-divider`, 날짜·메타 글자는 `--c-meta` 토큰으로 분리(화면 코드에 테마 분기 없이 기본 테마만 보조 글자색 사용).
- 선택 표시는 한 겹: 바깥 링을 겹치지 않고 테두리 자체를 강조색·3px로.
- 선명하게 보기 스위치는 켜짐/꺼짐 글자가 있는 진짜 스위치로.

## 검토한 대안
- 다크를 prefers-color-scheme 로만 유지: 사용자가 시스템과 다르게 고를 수 없어 기각.
- 선명하게 보기를 별도 테마로 추가: 3 × 2 × 2 조합이 늘고 테마마다 따로 맞춰야 해서, 어느 테마에도 얹히는 속성으로 구현.

## 참고
