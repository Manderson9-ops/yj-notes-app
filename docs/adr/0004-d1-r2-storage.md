# ADR-0004: 저장소로 Cloudflare D1 + R2

- 상태: 승인 (2026-09-28)
- 관련: docs/02-architecture.md, docs/04-security-privacy.md

## 배경
무료 운영(P5), Pages 와 같은 계정, "숫자는 자료에서 센다"(P3)를 SQL 집계로 구현하고 싶다.

## 결정
정형 자료(알림장·관측·검진·가족 기록)는 D1, 보고서 HTML·마크다운·검진 원본 사진은 R2(공개 접근 꺼짐). 스키마는 SQL 마이그레이션 파일로 관리한다.

## 결과
무료 한도 안에서 충분하고(02 §6), SQL 로 이식 가능하다. 사진·동영상 10GB 이상은 R2 무료 한도 초과라 1차 범위에서 제외한다.

## 검토한 대안
Supabase(기각: 별도 서비스·한도·지역), KV(기각: 집계 쿼리 불가), Google Sheets(기각: 보안·성능).
