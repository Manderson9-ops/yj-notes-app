# ADR-0001: 코드(공개)와 자료(비공개) 분리

- 상태: 승인 (2026-09-28)
- 관련: docs/02-architecture.md, docs/04-security-privacy.md

## 배경
D-01 로 저장소를 공개하기로 했다. 아이 자료가 한 번이라도 공개 저장소에 푸시되면 포크·캐시로 회수할 수 없다.

## 결정
코드·설계·합성 fixture 만 공개 저장소에 둔다. 실제 자료는 Drive(비공개 git)와 Cloudflare D1/R2 에만 둔다. 적재 CLI 는 `DATA_DIR` 로만 자료를 읽는다. 기존 비공개 자료 저장소는 원격에 푸시하지 않고, 신규 저장소는 이력 없이 시작한다.

## 결과
유출 방지를 사람의 주의가 아니라 구조와 가드(pre-commit·CI)로 강제한다. 대신 개발 시 실제 자료로 화면을 확인하려면 production 이 아닌 로컬 적재 경로가 필요하다(관리자 PC 에서만).

## 검토한 대안
비공개 저장소(기각: 사용자 결정 D-01), 자료 암호화 후 공개 저장소 커밋(기각: 키 관리 부담, 실수 시 평문 커밋 위험).
