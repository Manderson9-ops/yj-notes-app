# 테마 명세: 숲 (`data-theme="forest"`)

- What: 미야자키 하야오 그림체 연구(`style-study-forest.md`)를 앱 토큰·컴포넌트·장식으로 옮긴 구현 기준.
- Why: 연구 문서는 관찰·근거, 이 문서는 구현자가 그대로 따를 결정이다.
- How: §1 토큰을 `src/styles/themes/forest.css` 에, §2 컴포넌트 규칙을 같은 파일에, §3 장식을 `src/components/decor/` 에 구현한다.

화면 이름은 「숲」. 작품명·스튜디오명은 화면에 쓰지 않는다.

## 0. 그림체 → UI 핵심 번역 (연구 §2 → 결정)

| 그림체 특징 (연구) | UI 결정 |
|---|---|
| 인물·전경은 평면 셀, 질감은 배경에만 | **글자가 올라가는 면은 단색**. 수채 워시·종이 결은 바탕 층(`body` 뒤)과 장식에만 |
| 포스터컬러, 채도 낮춘 혼색, 젖은 경계 | 원색 금지. `radial-gradient` 2~3겹 워시(하늘 위, 숲 아래) |
| 하늘 비중 큰 구도, 공기 원근 | 헤더 영역에 하늘 워시, 언덕 2겹(뒤 연하게) 실루엣 장식 |
| 그림자에 푸른 기 | 그림자 `0 2px 10px rgba(40,73,95,.12)` |
| 가는 윤곽선 | 1px 장식선, 입력·키만 3:1 경계 |
| 바람·느린 움직임 | 장식 1개만 6~8s 흔들림, 전환은 opacity + 4px 이동 |
| 밤 장면의 짙은 청록·남색 | 다크 = 「밤의 숲」: 짙은 청록 바탕 + 달빛 크림 글자 + 작은 별 |

## 2. 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| 앱 헤더 | 하늘 워시 위 앱 이름(display), 아래 장식선 1px. 헤더 오른쪽 끝에 작은 구름 장식 |
| 주 버튼 | 숲 초록 면, 흰 글자, 라운드 14px, 푸른 기 그림자, 누르면 1px 내려감 |
| 보조 버튼 | surface 면 + `--c-border` 1px + 초록 글자 |
| 칩 | 알약형. 선택: 연초록 면 + 진초록 글자 + 체크 아이콘 |
| 카드 | surface 평면, 라운드 16px, 그림자. 위쪽 2px 하늘/숲 띠(장식) |
| 탭바 | surface 면, 위 장식선, 활성: 초록 아이콘·글자 + 위 3px 막대 |
| PIN 키패드 | 원형 64~72px, surface + `--c-border`, 숫자 본문 글꼴 28px. 화면 위에 언덕·구름 장식, 다크는 별·초승달 |
| 배지 | 햇빛 노랑 면 + 진한 글자 |
| 안내 상자 | 상태색 면 + 왼쪽 4px 막대 + 아이콘 + 글. 장식·모션 없음 |
| 빈 상태 | 하늘 워시 + 구름·언덕·잎 SVG(160px 이하) + 중립 문장 1줄. 잎 1개만 흔들림 |

**진지한 영역**: `data-tone="serious"` 안에서는 장식 숨김, 흔들림 정지.

## 3. 장식 SVG

| 이름 | 쓰는 곳 | 그리는 법 |
|---|---|---|
| `HillLayers` | PIN 화면 아래, 빈 상태 | 언덕 2겹, 뒤 언덕 연하게(공기 원근) |
| `CumulusCloud` | 헤더, PIN 화면 | 원 3~4개 합친 적운, 아래쪽에 연한 파랑 음영 |
| `Leaf` / `Sprout` | 빈 상태 | 잎 1장, 잎맥 1줄 |
| `WindLines` | PIN 화면 | 곡선 2~3줄, 끝 둥글게 |
| `MoonStars` | 다크 PIN·빈 상태 | 초승달 + 작은 별 3개 |

금지: 정령·동물·사람·탈것·특정 건물·장면 구도·트레이싱. 성장 단계를 식물 성장(새싹→나무)에 빗대는 표현 금지(판정처럼 읽힘).

## 4. 모션

| 상황 | 모션 | 줄인 동작 설정 |
|---|---|---|
| 장식 흔들림 | 화면당 1개, `rotate(±2deg)` 7s ease-in-out | 정지 |
| 화면 전환·카드 등장 | opacity + `translateY(4px)` 260ms | opacity 만 |
| 버튼 누름 | `translateY(1px)` + 그림자 축소 | 색만 |

## 5. 연구 대비 바꾼 점
