# 테마 명세: 크레용 (`data-theme="crayon"`)

- What: 「크레용 신짱」 그림체 연구(`style-study-crayon.md`)를 앱 토큰·컴포넌트·장식으로 옮긴 구현 기준.
- Why: 연구 문서는 관찰·근거, 이 문서는 구현자가 그대로 따를 결정이다. 둘을 나눠 근거와 결정을 따로 고칠 수 있게 한다.
- How: §1 토큰을 `src/styles/themes/crayon.css` 에, §2 컴포넌트 규칙을 같은 파일에, §3 장식을 `src/components/decor/` 에 구현한다.

화면 이름은 「크레용」. 작품명·캐릭터명은 화면에 쓰지 않는다.

## 0. 그림체 → UI 핵심 번역 (연구 §3 → 결정)

| 그림체 특징 (연구) | UI 결정 |
|---|---|
| 굵고 균일한 둥근 외곽선, 갈색빛 검정 먹선 | 카드·버튼·칩·키에 2.5~3px 먹선(`--bw: 3px`), 선 색 `#2A1F1C` |
| 평면 채색, 그림자·그라데이션 거의 없음 | 블러 없는 오프셋 단색 그림자 `3px 3px 0`. 그라데이션 금지 |
| 넓은 파스텔 면 + 원색 포인트 | 바탕 크림, 섹션 면 하늘·연분홍·연노랑, 포인트 파랑·빨강·노랑 |
| 단순한 형태, 움직임으로 개성 | 평소 정지, 누름·저장 때만 튀는 모션(overshoot) 1회 |
| 크레용 질감은 작품 특징이 아님(관찰) | 크레용 낙서는 **테마의 해석**. 장식(밑줄·낙서 별·구름)에만 |

## 2. 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| 앱 헤더 | 하늘 면(`--c-surface-2`), 아래 경계는 흔들린 크레용 선 SVG(장식), 앱 이름 display 글꼴 |
| 주 버튼 `.btn-primary` | 파랑 면·흰 글자·먹선 3px·오프셋 그림자, 높이 52px. 누르면 그림자 0 + `translate(2px,2px)` + overshoot |
| 보조 버튼 `.btn` | 흰 면·먹선·글자 `--c-fg` |
| 칩 `.chip` | 알약형. 선택: 노랑 면 + 체크 아이콘 + `aria-pressed` (색만으로 구분 금지) |
| 카드 `.card` | 흰 면·손그림 먹선·라운드 16px·오프셋 그림자. 위쪽 12px 파스텔 띠(`--c-band-sky`/`--c-deco-2`/`--c-deco-3`): 같은 부모 안 **형제 순서(`nth-child` 3n+1/3n+2/3n)** 로 하늘→분홍→노랑이 돌아가는 장식이며 의미 없음. 진지한 영역에서는 띠와 위 여백을 함께 뺌 |
| 손그림 외곽선 | 카드·버튼·칩·입력·테마 선택지·PIN 키: 살짝 흔들린 둥근 선(**`border-image` 9-slice 정적 SVG data URI**, rect/pill/circle 3종 × 라이트·다크 색). 면(배경)은 `background-clip: padding-box` 로 선 안쪽에 가둬 모서리에서 선 밖으로 삐져나오지 않게 하고, 그림자는 `filter: drop-shadow(3px 3px 0 var(--c-shadow))` 로 선+면 묶음 모양을 따라 선 바로 뒤에 붙는다. focus outline 은 기하 도형 그대로(접근성). 안내 상자·배지는 직선 테두리 유지 |
| 크레용 결 | 낙서 SVG 는 정적 `feTurbulence` 필터로 채움·선 일부가 비치게(장식 안에서만). h2 형광펜은 `clip-path: polygon` 으로 거친 가장자리 |
| 탭바 | 활성 탭: 굵은 라벨(Jua 는 굵기가 하나뿐이라 글자 둘레선 0.5px 로 굵게) + 라벨 아래 크레용 밑줄(SVG, `stroke-dashoffset` 250ms) |
| PIN 키패드 | 원형 72px 키, 흰 면·먹선, 숫자는 **본문 글꼴** 28px(큰 글씨 땐 비례) tabular-nums. 확인 키 파랑 면 |
| 배지 `.badge` | 노랑 면 + 먹선 1.5px + 글자 `--c-fg` |
| 섹션 제목 `h2` | 파스텔 형광펜 띠(`--c-hl`) 위에 `--c-on-hl` 글자, 살짝 기울임(장식) |
| 라디오(테마 고르기) | `appearance:none` 먹선 원 + 선택 시 안쪽 채운 점 |
| 안내 상자 `.notice` | `data-tone="warn|alert|info|ok"`: 상태색 면 + 아이콘 + 글. **직선 테두리, 장식·모션 없음** |
| 빈 상태 `.empty` | 연분홍(`--c-hl`) 면 + 손그림 선 카드, 안에 크레용·구름·집 낙서 SVG + `--c-on-hl` 문장 1줄 |
| PIN 화면 | 위쪽(`min(40dvh, 320px)`)에 하늘색(`--c-surface-2`) 넓은 면 + 헤더처럼 흔들린 크레용 아래선(글자 대비는 `fg·muted / surface-2` 짝이 확인) |

**진지한 영역**: `data-tone="serious"` 가 붙은 영역(검진·성장·주의 안내) 안에서는 장식 SVG 숨김, 오프셋 그림자·튀는 모션 끔.

## 3. 장식 SVG (오리지널, `aria-hidden`, `pointer-events:none`)

| 이름 | 쓰는 곳 | 그리는 법 |
|---|---|---|
| `CrayonUnderline` | 헤더 아래, 활성 탭 | 살짝 물결진 굵은 선 1개, 끝 둥글게 |
| `DoodleStar` / `DoodleCloud` / `DoodleSun` | PIN 화면 위, 빈 상태 | 비뚤어진 손그림 path, 먹선 2.5px + 원색 평면 채움 |
| `CrayonStick` | 빈 상태, 미리보기 | 원통 + 뾰족 끝, 종이 띠 |
| `DoodleHouse` | 빈 상태(홈·자료) | 삼각 지붕 + 네모 + 창 2개(일반 사물) |
| `DoodleGround` | PIN 화면 아래 | 길게 흔들린 땅 선 1줄 + 풀 3포기(하단 고정, 키패드 뒤) |
| `DoodleUmbrella` | 빈 상태(기록) | 기울어진 펼친 우산(생활 속 엉뚱한 순간) |
| `DoodleBall` | 빈 상태(알림장·자료) | 튀는 공 + 땅 그림자 + 움직임 선 2줄 |
| `DoodlePuddle` | 빈 상태(기록·자료) | 납작한 물웅덩이 + 물결 2줄 |

빈 상태 조합은 화면(`variant`)마다 다르다: 홈 = 집·구름·크레용, 기록 = 우산·웅덩이·별, 알림장 = 공·구름·크레용, 자료 = 집·공·웅덩이.

금지: 사람·동물·얼굴·실루엣, 엉덩이 등 개그 모티프, 채점 기호(동그라미/X), 로고 글자 배치.

## 4. 모션

| 상황 | 모션 | 줄인 동작 설정 |
|---|---|---|
| 버튼·키 누름 | 누르는 동안 `translate(2px,2px)` + 그림자 0. 뗄 때 scale .94 → 1.04 → 1 (220ms overshoot, 포커스가 남은 버튼에서 1회 재생 — Safari 터치처럼 포커스가 안 남는 경우엔 생략됨) | 색 변화만 |
