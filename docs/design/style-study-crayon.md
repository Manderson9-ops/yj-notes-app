# 스타일 연구: 크레용 낙서풍 생활 만화 테마 (「크레용 신짱」 그림체 분석 기반)

- **What**: 「크레용 신짱」(원작 우스이 요시토, 애니 신에이동화)의 그림체 특징만 뽑아, 캐릭터·로고·장면 없이 쓸 수 있는 오리지널 UI 테마 규칙으로 바꾼다.
- **Why**: 가족 기록 앱에 "밝고 장난스러운 생활 만화" 느낌의 선택 테마를 주되, 공개 저장소의 저작권·상표 위험과 조부모 가독성(AA 4.5:1, 17px, 48px 터치)을 동시에 지키기 위해서.
- **How**: 1차 자료(공식 사이트 관찰, 제작진 인터뷰) → 시각 특징 표 → 색·선·타이포·모션 토큰 → 컴포넌트 적용 예 → 앱 원칙 충돌 점검 → Do/Don't.

표기: (출처)는 각주 URL, (관찰)은 공식 사이트 키 비주얼을 브라우저로 보고 픽셀 샘플링한 결과[^tvasahi], (추론)은 관찰·출처에서 끌어낸 해석. 이미지는 저장소에 저장하지 않았다.

## 2. 제작진 발언에서 본 스타일 원칙

| 발언 요지 | 출처 | UI로의 시사점 (추론) |
|---|---|---|
| 캐릭터 자체가 **단순**해서 다양한 움직임을 시험할 수 있었다. 만화적 데포르메부터 뼈를 의식한 리얼 지향까지 폭이 넓다 (유아사 마사아키) | [^cinematoday] | 형태는 최소로, 움직임(모션)에 개성을 싣는다 |
| 주인공의 **머리 형태는 '거짓말'**(입체적으로 맞지 않음)이라 입체로 그리려 하면 어려워진다. 진지하게 따지면 오히려 재미없어지고, **기억의 단편처럼 단순하게** 그리면 좋은 디자인이 된다 (유아사) | [^cinematoday] | 원근·입체감 그림자보다 평면 기호. 아이콘은 "정확함"보다 "알아보기 쉬움" |
| 초기 주인공은 **많이 움직이지 않는 캐릭터** — 최소 노력으로 최대 효과 (하라 케이이치) | [^cinematoday] | 평상시는 정적, 포인트에서만 크게 튄다 |
| 원화가마다 개성이 강함: "엉망처럼 보이는데 화면에선 재밌는" 원화와 "액자에 걸고 싶을 만큼 깔끔한" 원화가 공존 (유아사) | [^cinematoday] | 선의 '흔들림'은 작품 고유 규칙이 아니라 작가별 편차 → UI는 한 가지 선 규칙으로 통일 |
| 원작자: 주인공은 "정면으로 웃지 않는 하드보일드" (나카지마 가즈키 전언) | [^cinematoday] | 유머는 과장된 웃음 표정이 아니라 **엉뚱한 타이밍·포즈**에서 나온다 |

## 3. 시각 특징 분석

### 3.1 선 (line)

| 항목 | 특징 | 표시 |
|---|---|---|
| 굵기 | 외곽선이 굵고 진하다. 내부 디테일 선은 더 적고 얇다 | (관찰) 공식 키 비주얼 |
| 일정성 | 붓 터치식 강약보다 **거의 균일한 굵기**의 단색 선 | (관찰) |
| 선 색 | 순흑이 아닌 **아주 어두운 갈색빛 검정** 근사 `#221715` | (관찰, 픽셀 샘플) |
| 모서리 | 끝이 둥글고, 각진 꺾임이 적다 | (관찰) |
| 손그림 흔들림 | 디지털 키 비주얼에서는 매끈함. 원화가별로 선 질감 편차가 크다는 증언은 있음 | (관찰) + [^cinematoday] |

### 3.2 형태 언어

- 극단적 단순화: 얼굴 요소 최소, 큰 머리 + 짧고 작은 몸(유아 체형의 데포르메). (관찰)
- 기하형 기반이지만 **입체적으로 맞지 않는 형태**를 의도적으로 유지(머리 형태). [^cinematoday]
- 사물도 윤곽선 + 평면 채색의 "기호"처럼 처리. (관찰/추론)

### 3.3 색

| 역할 | 근사 hex | 표시 |
|---|---|---|
| 원색 빨강 | `#E3002C` | (관찰, 픽셀 샘플) |
| 원색 파랑 | `#0478C0` | (관찰) |
| 진한 노랑 | `#FFF107` | (관찰) |
| 연노랑(배경·별) | `#FFF796` / `#FEF696` | (관찰) |
| 하늘색 배경 | `#D7EDF8` | (관찰) |
| 연파랑 | `#8CBDD7` | (관찰) |
| 연분홍(구름) | `#FFD4DA` | (관찰) |
| 주황 | `#FD9D53` | (관찰) |
| 선/머리 검정 | `#221715` ~ `#2B201E` | (관찰) |
| 갈색 본문 글자 | `#4F3216` | (관찰, 사이트 UI 글자) |

- 채색은 **평면(flat)**, 그라데이션·입체 그림자가 거의 없다. (관찰)
- 구성: 원색(빨·파·노) 포인트 + 넓은 **파스텔 배경**(하늘색·연노랑·연분홍). (관찰)
- 한계: 위 값은 TV아사히 공식 사이트 키 비주얼(웹용 일러스트) 1개 기준. 방송 화면의 실제 색 지정과 다를 수 있다.

### 3.4 배경

- 무대가 가스카베의 일상(집, 동네, 유치원) → **생활 공간 중심**. [^wiki-en]
- 배경은 캐릭터보다 단순·연한 톤으로 물러나는 경향 (추론, 키 비주얼의 넓은 파스텔 면 관찰 기반).

### 3.5 질감: '크레용'은 어디서 오나

| 구분 | 판단 |
|---|---|
| 실제 그림(키 비주얼) | 평면 디지털 채색, 크레용 결·종이 질감 없음 (관찰) |
| 제목의 '크레용' | 질감보다 **아이·낙서·유치원** 연상을 주는 이름 이미지 (추론). 제목 유래의 1차 출처는 찾지 못함(검증 못 함) |
| 결론 | 크레용 질감은 **작품의 그림체 특징이 아니라 테마의 오리지널 해석**으로 쓰고, 텍스트 영역에는 넣지 않는다 (추론) |

### 3.6 레터링·로고 분위기

- 공식 로고는 굵고 둥근, 여러 색이 섞인 손글씨풍 타이틀 (관찰). **형태·배색·글자 배치 복제 금지.**
- 테마에서는 "굵고 둥근 손글씨 제목"이라는 **일반적 분위기**만 무료 폰트로 표현한다.

### 3.7 감정·유머 톤, 구도

- 개그 만화 장르 [^wiki-ja]. 유머는 정면 웃음보다 엉뚱함·과장 동작 [^cinematoday].
- 평소엔 덜 움직이고 포인트에서 크게 과장 [^cinematoday] → 정지와 튐의 대비.
- 진지한 장면(가족애, 이별)도 같은 그림체 안에서 다룬다 [^cinematoday] → 단순한 그림체가 진지한 내용과 공존 가능 (추론).

### 4.2 테두리·라운드·그림자

| 규칙 | 값 | 근거 |
|---|---|---|
| 외곽선 | 2.5~3px 실선 `--border` (먹선) | 굵고 균일한 외곽선 (관찰) |
| 라운드 | 카드 16px, 버튼 14px, 칩 999px | 둥근 선 끝 (관찰) |
| 그림자 | 블러 없는 **오프셋 단색 그림자** `3px 3px 0 var(--border)` | 평면 채색·입체 그림자 없음 (관찰)을 UI식으로 해석 (추론) |
| 손그림 느낌 | 장식 요소에만 SVG `feTurbulence`+`feDisplacementMap`(scale 1~2) 또는 미리 그린 흔들린 path. **텍스트·입력칸 테두리에는 적용 금지** | 가독성 |
| 크레용 질감 | 헤더 띠·빈 상태 일러스트에만, 불투명도 낮게 | 3.5 결론 |

### 4.4 아이콘·일러스트 모티프 (오리지널 SVG만)

| 허용 모티프 | 그리는 규칙 |
|---|---|
| 크레용 한 자루(일반 원통+뾰족 끝), 크레용 선 긋기 | 먹선 2.5px + 평면 원색 채움 |
| 낙서 별·하트·해·꽃·구름 | 살짝 비뚤어진 손그림 path, 5각 별은 끝이 둥글게 |
| 집(삼각 지붕+네모), 창문, 대문 | 일반 사물. 특정 작품 속 집 형태 참고 금지 |
| 신발, 가방, 숟가락, 밥그릇, 체온계, 달력 | 알림장·발달 기록 관련 일상 사물 |
| 동그라미 표시·밑줄·화살표 낙서 | 강조용. 판정 의미(정답 동그라미/오답 X) 금지 |

- 사람·동물 얼굴, 캐릭터 실루엣, 엉덩이 등 작품 연상 개그 모티프 금지.
- 아이콘 크기 24px 기준, 터치 영역은 48px 확보.

### 4.5 모션

| 상황 | 모션 | reduced-motion |
|---|---|---|
| 버튼 누름 | `scale(0.94)` → `1.04` → `1` (overshoot, 220ms, `cubic-bezier(.34,1.56,.64,1)`) | 색 변화만 |
| 저장 완료 | 낙서 별이 한 번 튀었다 사라짐 (400ms) | 정적 체크 + 텍스트 |
| 탭 전환 | 밑줄 크레용 선이 그려짐 (`stroke-dashoffset`, 250ms) | 즉시 표시 |
| 빈 상태 | 일러스트가 느리게 2° 흔들림 1회 | 없음 |

- 평소 정지, 포인트에서만 튐 → 2장 하라 감독 발언의 "최소 노력·최대 효과" 해석 (추론).
- `@media (prefers-reduced-motion: reduce)`에서 transform·keyframes 전부 끔. 반복 애니메이션 금지.

| 보조 버튼 | 면 `--surface`, 글자 `--text`, 먹선 | |
| 칩 | 비선택: 흰 면+먹선 / 선택: `--yellow` 면 + 글자 `--text` + 체크 아이콘 | 색만으로 상태 구분 금지 |
| 카드 | 면 `--surface`, 먹선 2.5px, 라운드 16px, 상단에 파스텔 띠(하늘·분홍·연노랑 순환) | 띠는 장식, 의미 없음 |
| 탭바 | 높이 64px, 활성 탭: 크레용 밑줄 + 굵은 라벨 + 아이콘 채움 | 라벨 항상 표시 |
| PIN 키패드 | 72px 원형 키, 먹선 + 흰 면, 숫자는 본문 폰트 28px | 누름 모션만 튐, 입력 점은 단순 원 |
| 배지 | `--yellow` 면 + `--text` 글자, 낙서 별 테두리는 장식 | 개수·새 글 표시용 |
| 빈 상태 | 크레용·구름·집 일러스트 + 중립 문장("아직 기록이 없어요") | 장난 문구 대신 안내 |
| 주의 안내 | `--caution-bg`, `--caution-text`, 일반 정보 아이콘, **장식 없음·직선 테두리** | 4장 참고 |

## 5. 앱 원칙과의 충돌 점검

| 원칙 | 충돌 지점 | 해결 |
|---|---|---|
| 판정 어휘 금지 | 개그풍 문구가 아이를 "잘했다/못했다"로 놀리는 톤이 될 수 있음. 동그라미/X 낙서가 채점 기호로 읽힘 | 유머는 **시각(모션·장식)에만**. 문구는 기본 테마와 동일한 중립 문장. 채점 기호 모티프 금지 |
| 조부모 가독성 | 손글씨 본문, 흔들리는 선, 저대비 파스텔 글자 | 본문은 고딕 17px, 손글씨는 제목만. 파스텔은 면만, 글자는 항상 `--text` |
| 진지한 건강 정보 | 원색 빨강이 경고처럼, 튀는 모션이 가볍게 보임 | 건강·주의 화면에서는 장식·튐·손그림 필터 **자동 해제**(`data-tone="serious"`) |
| 경고 vs 원색 | 테마의 빨강·노랑과 경고색이 겹침 | 경고는 별도 토큰(`--caution-*`, 주황갈색 계열) + 아이콘 + 텍스트 라벨 3중 표시. 테마 빨강은 선택 표시·장식에만, 경고 의미로 쓰지 않음 |
| 터치 48px | 낙서 별 등 장식이 작은 클릭 대상이 될 수 있음 | 장식은 `pointer-events:none`, 실제 대상은 48px 이상 |

유머 허용 범위 요약: 홈·빈 상태·저장 완료 = 허용 / 기록 입력 = 최소 / 건강·발달 수치·알림장 공지 = 금지.

## 6. Do / Don't

| Do | Don't |
|---|---|
| 굵고 균일한 둥근 먹선, 평면 채색, 파스텔 넓은 면 + 원색 포인트 | 작품 주인공·가족·친구·애완견(흰 강아지 등)·극중 히어로(액션가면 등) 형상, 실루엣, 패러디 |
| 일반 사물(크레용, 별, 구름, 집) 오리지널 SVG | 공식 로고 형태·배색·글자 배치 모방, 작품 제목·캐릭터명 UI 노출 |
| 테마 이름은 일반명("크레용 낙서", "생활 만화") | 테마 이름·설명에 작품명/캐릭터명 사용, "공식" 오인 표현 |
| 굵고 둥근 무료 OFL 폰트로 분위기만 | 극중 대사·말버릇·특정 효과음 문자·개그 포즈(엉덩이 등) 재현 |
| 관찰 색을 출발점으로 조정한 자체 팔레트 | 공식 이미지·스크린샷·원화를 저장소·번들에 포함, 트레이싱 |
| 진지한 화면에서 장식 자동 해제 | 경고를 테마 빨강으로 표시, 색만으로 상태 구분 |
| 문서·커밋에 출처 표기 | 실제 아이·가족 정보 예시 사용 |

법적 주의(추론): 그림체 자체가 상표 분쟁 대상이 된 사례가 있으므로[^wiki-ja], "그 작품처럼 보이는가"를 리뷰 체크 항목으로 둔다. 완성 화면을 작품을 모르는 사람이 봤을 때 특정 작품을 떠올리지 않을 정도의 일반화를 목표로 한다.
